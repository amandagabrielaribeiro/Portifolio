# 🌟 Projeto Final - Módulo 5 (HTML5 e CSS3)

Projeto desenvolvido como conclusão do Módulo 5 do curso de **HTML5 e CSS3** do **Curso em Vídeo**, ministrado pelo professor Gustavo Guanabara.

## 💻 Sobre o Projeto
Este projeto consiste na criação de um site completo e responsivo, aplicando conceitos avançados de estruturação e estilização moderna para fixar todo o aprendizado do módulo.

## 🛠️ Tecnologias e Conceitos Utilizados
* **HTML5:** Estrutura semântica e organizada.
* **CSS3:** Estilização avançada, paleta de cores e tipografia.
* **Flexbox & CSS Grid:** Técnicas modernas para alinhamento e criação de layouts complexos e adaptáveis.
* **Media Queries:** Design responsivo para diferentes tamanhos de tela (mobile e desktop).
* **Git e GitHub:** Versionamento e publicação do código.

## 🚀 Como acessar
Você pode visualizar o projeto funcionando diretamente através do link do GitHub Pages (se estiver ativado) ou clonando este repositório em sua máquina.
